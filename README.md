# DulceBot – Repositorio documental del proyecto

**Autor:** Jerson Javier Jiménez Bolaños  
**Proyecto:** DulceBot – Chatbot inteligente para ventas e inventario  
**Cliente ficticio:** Dulce Andina S.A.S.  
**Código:** DB-2026-01

## Descripción

DulceBot es un prototipo de chatbot inteligente para consultar productos, precios y disponibilidad, calcular pedidos y registrar únicamente las ventas confirmadas por el cliente.

La solución utiliza n8n, Supabase, inteligencia artificial, Calculator y ClickUp como herramienta de gestión.

## Organización

- `01_Analisis`: formulación, acta, problema, objetivos, alcance e interesados.
- `02_Diseno`: requisitos, planificación, EDT, cronograma y riesgos.
- `03_Desarrollo`: presupuesto, hardware, infraestructura, alojamiento y ClickUp.
- `04_Pruebas_y_Calidad`: plan de calidad, pruebas, criterios y resultados.
- `05_Cierre_y_Metodologia`: metodología, informe final, lecciones aprendidas y conclusiones.

El repositorio contiene documentos editables en Word y el informe final también en PDF para facilitar su lectura.

## Metodología

Se utilizó una metodología híbrida, combinando planificación predictiva con ejecución ágil mediante Kanban en ClickUp.

## Informe final

El documento `09_Informe_Final_Cierre_DulceBot.pdf` resume el desarrollo, alcance, funcionalidades, pruebas, cronograma, presupuesto, problemas, riesgos, lecciones aprendidas, recomendaciones y conclusiones.
